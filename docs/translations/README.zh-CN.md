# FH2 Horizon Radio

## 快速入门

通过 Azimuth，在 Forza Horizon 2 电台中播放你的 YouTube 音乐队列。

下载最新版本，将 horizon-radio 解压到 azimuth.exe 旁边。打开 FH2 Radio.exe，添加视频链接并启用电台。在游戏中选择偏好设置指定的替换电台。

音频通过游戏混音器播放，保留嘉年华音效。队列随游戏暂停和电台切换而暂停。默认语言为英语，另有八种可选翻译。

更新前退出应用并保留 runtime。要恢复原始名称和标志，请关闭 FH2，然后在偏好设置中恢复。

需要 Windows x64、Azimuth 0.9.10 和你自己合法安装的 FH2 1.0.0.64。其他版本尚未确认兼容。源代码保持私有。
