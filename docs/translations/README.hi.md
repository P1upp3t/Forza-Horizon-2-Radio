# FH2 Horizon Radio

## त्वरित शुरुआत

Azimuth पर Forza Horizon 2 के रेडियो में अपनी YouTube संगीत कतार सुनें।

नवीनतम संस्करण डाउनलोड करें और horizon-radio को azimuth.exe के पास निकालें। FH2 Radio.exe खोलें, वीडियो लिंक जोड़ें और रेडियो चालू करें। गेम में पसंद के अंतर्गत चुना गया स्टेशन चुनें।

ऑडियो गेम के मिक्सर और फ़ेस्टिवल प्रभावों का उपयोग करता है। गेम रुकने और स्टेशन बदलने पर कतार रुकती है। अंग्रेज़ी डिफ़ॉल्ट है; आठ अन्य अनुवाद वैकल्पिक हैं।

अपडेट से पहले ऐप बंद करें और runtime रखें। मूल नाम और लोगो वापस लाने के लिए FH2 बंद करके पसंद में पुनर्स्थापना का उपयोग करें।

Windows x64, Azimuth 0.9.9 और आपका अपना वैध FH2 1.0.0.64 इंस्टॉलेशन आवश्यक है। अन्य बिल्ड की अनुकूलता की पुष्टि नहीं हुई है। स्रोत कोड निजी है।
