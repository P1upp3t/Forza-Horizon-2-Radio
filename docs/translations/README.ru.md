# FH2 Horizon Radio

## Краткое руководство

Слушайте очередь YouTube на радиостанции Forza Horizon 2 через Azimuth.

Скачайте последнюю версию и распакуйте horizon-radio рядом с azimuth.exe. Откройте FH2 Radio.exe, добавьте ссылки на видео и включите радио. В игре выберите станцию, указанную в настройках.

Звук проходит через микшер игры с эффектами Фестиваля. Очередь следует паузам и переключениям станций. По умолчанию используется английский; доступны восемь переводов.

Перед обновлением закройте приложение и сохраните runtime. Для возврата оригинального названия и логотипа закройте FH2 и используйте восстановление в настройках.

Требуются Windows x64, Azimuth 0.9.9 и собственная легальная установка FH2 1.0.0.64. Другие сборки не проверены. Исходный код остаётся закрытым.
