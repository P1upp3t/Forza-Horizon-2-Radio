# FH2 Horizon Radio

## دليل البدء السريع

استمع إلى قائمة موسيقى YouTube عبر محطة راديو Forza Horizon 2 على Azimuth.

نزّل أحدث إصدار واستخرج horizon-radio بجوار azimuth.exe. افتح FH2 Radio.exe وأضف روابط الفيديو وشغّل الراديو. اختر داخل اللعبة المحطة المحددة في التفضيلات.

يمر الصوت عبر مازج اللعبة مع تأثيرات المهرجان. تتوقف القائمة مع توقف اللعبة أو تغيير المحطة. الإنجليزية هي الافتراضية، مع ثماني ترجمات اختيارية.

أغلق التطبيق قبل التحديث واحتفظ بمجلد runtime. لاستعادة الاسم والشعار الأصليين، أغلق FH2 واستخدم الاستعادة في التفضيلات.

يتطلب Windows x64 وAzimuth 0.9.10 ونسختك المثبتة بشكل قانوني من FH2 1.0.0.64. لم يُؤكد توافق الإصدارات الأخرى. يبقى الكود المصدري خاصًا.
