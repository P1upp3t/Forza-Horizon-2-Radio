# FH2 Horizon Radio

## Guide rapide

Écoutez votre file YouTube sur une station de Forza Horizon 2 avec Azimuth.

Téléchargez la dernière version et extrayez horizon-radio à côté de azimuth.exe. Ouvrez FH2 Radio.exe, ajoutez des liens vidéo et activez la radio. Sélectionnez dans le jeu la station choisie dans les Préférences.

Le son passe par le mixeur du jeu et conserve les effets du Festival. La file suit les pauses et les changements de station. Anglais par défaut, huit traductions facultatives.

Fermez l’application avant la mise à jour et conservez runtime. Pour restaurer le nom et le logo d’origine, fermez FH2 et utilisez la restauration dans les Préférences.

Nécessite Windows x64, Azimuth 0.9.10 et votre propre installation légitime de FH2 1.0.0.64. Les autres versions ne sont pas confirmées. Le code reste privé.
