# FH2 Horizon Radio

## Guía rápida

Lleva tu cola de música de YouTube a una emisora de Forza Horizon 2 en Azimuth.

Descarga la última versión y extrae horizon-radio junto a azimuth.exe. Abre FH2 Radio.exe, añade enlaces de vídeos y activa la radio. Selecciona en el juego la emisora elegida en Preferencias.

El audio usa el mezclador del juego y los efectos del Festival. La cola sigue las pausas y los cambios de emisora. Inglés es el idioma predeterminado, con ocho traducciones opcionales.

Para actualizar, cierra la aplicación y conserva runtime. Para restaurar el nombre y logo originales, cierra FH2 y usa la restauración en Preferencias.

Requiere Windows x64, Azimuth 0.9.9 y tu propia instalación legítima de FH2 1.0.0.64. Otros builds no están confirmados. El código permanece privado.
