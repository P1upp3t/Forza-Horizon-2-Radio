# FH2 Horizon Radio

## দ্রুত শুরু

Azimuth-এ Forza Horizon 2-এর রেডিও স্টেশনে আপনার YouTube গানের তালিকা শুনুন।

সর্বশেষ সংস্করণ ডাউনলোড করে azimuth.exe-এর পাশে horizon-radio আনজিপ করুন। FH2 Radio.exe খুলে ভিডিও লিংক যোগ করুন এবং রেডিও চালু করুন। গেমে পছন্দের সেটিংসে বেছে নেওয়া স্টেশনটি নির্বাচন করুন।

অডিও গেমের মিক্সার ও ফেস্টিভ্যালের প্রভাব ব্যবহার করে। গেম থামলে বা স্টেশন বদলালে তালিকা থামে। ইংরেজি ডিফল্ট, আরও আটটি অনুবাদ ঐচ্ছিক।

আপডেটের আগে অ্যাপ বন্ধ করে runtime রাখুন। মূল নাম ও লোগো ফেরাতে FH2 বন্ধ করে পছন্দের সেটিংসে পুনরুদ্ধার ব্যবহার করুন।

Windows x64, Azimuth 0.9.10 এবং নিজের বৈধ FH2 1.0.0.64 ইনস্টলেশন প্রয়োজন। অন্য বিল্ডের সামঞ্জস্য নিশ্চিত নয়। সোর্স কোড ব্যক্তিগত থাকবে।
